# Backend

## Setup

```bash
npm install
npm run dev
```

## Environment Variables

- `PORT` (default `4000`)
- `JWT_SECRET` (default `dev-secret-change`)
- `LAB_IMAGE` (default `ubuntu:22.04`)
- `LAB_CPU_SHARES` (default `256`)
- `LAB_MEMORY_BYTES` (default `536870912`)
- `LAB_SESSION_TIMEOUT_MS` (default `3600000`)
- `LAB_NETWORK` (default `bridge`)
- `CORS_ORIGIN` (default `*`)
